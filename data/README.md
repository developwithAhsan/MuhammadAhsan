# DATA INBOX — Mohammad Ahsan Portfolio

Upload any unorganised portfolio material into this folder. You do not need to rename or sort it first.

## What you can upload
- Website screenshots, URLs in a .txt file, and project notes
- Google Search Console screenshots / exports
- Monetag or AdSense performance screenshots (please crop account email, manager name, account IDs, payment details and other private data)
- Certificates (JPG, PNG, WEBP or PDF)
- Video thumbnails, YouTube links, storyboards and AI-video samples
- Any other work samples you want reviewed

## How to upload from GitHub on mobile
1. Open the repository: https://github.com/developwithAhsan/MuhammadAhsan
2. Open the `data` folder.
3. Tap **Add file** → **Upload files**.
4. Select your files from the device. You can upload multiple files together.
5. Scroll down, enter a commit message such as `Add portfolio source material`, and tap **Commit changes**.

## Important
- Keep private credentials, login screenshots, recovery codes, account IDs, payment details and personal contact information out of this folder.
- Do not worry about arranging the files. I can review the uploaded material and then organise selected, safe-to-publish items into the single-page portfolio.
- Files in this folder are an inbox; only approved public-facing material should be displayed on the live website.
