# Mohammad Ahsan — Professional Video Creator

A single-page, light-theme portfolio for Mohammad Ahsan.

## Homepage order
1. Hero and social links
2. Content creation and AI product ads
3. Website directory, project thumbnails and performance screenshots
4. Three course certificates
5. Skills and tools
6. About
7. Contact

## Source material
- The `data/` folder stores the uploaded source material.
- The homepage displays the three actual certificate images and the uploaded Search Console / Monetag reports.
- The college logo is not displayed.
- The Monetag screenshot has its account header and left navigation covered for privacy.
- Only the uploaded public-safe statistics are shown. No sign-in details, account identifiers or payment details are published.

## Video samples
The Content Creation section is ready for the owner's own public-safe ad videos. Add video links when available. Private client work should not be published without permission.

## Deploy
This is a static website. Cloudflare Pages uses the repository root as the build output directory and does not need a build command.
